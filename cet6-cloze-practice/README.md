# 六级选词填空点对点练习

一个用于六级选词填空的轻量学习网站。重点是把背过的单词和具体语境中的意思对应起来。

## 已实现

- **语境短练**：38 个基础词，76 道原创单句题。比较词义、搭配和干扰项。
- **词汇表**：按 en、em、im、re、de 词缀家族、词性、首字母和关键词筛选。词卡有例句、译文、用法与词典链接。
- **每日词缀**：em → en → im → re → de，五天一轮，从首次打开网站的北京时间日期开始。不同于按字母开头强行拆词。
- **真题备选词**：按当天推荐试卷学习完整 15 个备选词，含未被选中的词。
- **复习**：先回忆、再翻卡；还不熟的词当天再看，记住的词按 1、3、7、14、30 天安排。一天内反复点击“记住了”不连续提升间隔。
- **真题练习**：首批 4 套（2024 年 12 月 2 套、2025 年 6 月 2 套），共 60 个备选词、40 空。支持唯一选词、判分、讲解、记录与重做。
- **原文使用**：从来源链接阅读，也可粘贴持有的题目，在当前浏览器内保存。源代码不分发原文。

## 运行

进入本目录后，需要 Node.js 18+。安装依赖并启动：

```sh
npm install
npm run build
npm run dev
```

打开 `http://localhost:4173`。直接使用完整源码包时字体已经包含，无须安装应用运行依赖。GitHub 源码版本在构建时从安装的字体包复制字体。

`npm run build` 把 `public` 复制到 `dist`，任何静态托管都可部署该目录。Sites 访问控制属于托管配置，开源程序本身不提供账号认证；公开部署前应自行确定访问范围。原来的私人 Sites 站点继续保持原权限。

## 检查

```sh
npm test
```

`npm test` 检查词库结构、真题选项与答案映射、北京时间轮换和复习间隔。`qa/upgrade-report.json` 记录桌面与手机交互验证结果。

## 数据范围

此项目不是完整历年真题库，也不代表考试词频排行。真题参考答案来自机构与公开学习来源，不称为官方标准答案；文章套次存在不同标法时，在界面注明。释义和例句为本项目编写，词卡可跳转原词典核对。

学习记录与粘贴的原文存在当前浏览器的 localStorage，不跨设备同步。清理站点数据会移除这些记录。

## 目录

- `public/data.js`：en / im / re / de 基础词与原创短练
- `public/affixes.js`：em 词族、轮换课程、精准义项
- `public/exams.js`：真题来源、备选词、参考答案与原创讲解
- `public/learning.js`：北京时间、词缀轮换与复习间隔
- `public/upgrade.js`：每日背词与真题交互
- `public/app.js`：短练与词汇表
